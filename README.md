# Shamika Achinthya — Software, Systems & Automation

Cinematic, responsive React/Vite portfolio, hosted on GitHub Pages.

### Themes
- **Eclipse** — navy/blue dark mode
- **Halo** — light mode

The four sections use all eight user-supplied original images from `public/backgrounds/`, without renaming them. Only the active theme image is loaded for a given section.

### Local development
```bash
npm install
npm run dev
npm run lint
npm run build
```

### Deployment
`.github/workflows/deploy.yml` publishes `dist/` to GitHub Pages when you push to `main` after setting Pages → Source to **GitHub Actions**.

See `PORTFOLIO_README.md` for installation instructions and background mapping.
